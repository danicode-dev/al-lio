## Rollback

If the web service fails readiness or the authenticated smoke test, recreate
only `al_lio_web` from the previous immutable release directory. Do not rebuild,
restart or restore Radar or PostgreSQL for a web-only regression.

The executable procedure is maintained in
[`../release-and-rollback.md`](../release-and-rollback.md) and the private VPS
runbook stored outside the public repository.
