# Archivo Histórico

Esta carpeta conserva documentación que ya no representa el estado actual del proyecto.

Motivos habituales de archivo:

- menciona Supabase como base de datos o auth actual;
- menciona Vercel como despliegue actual;
- usa nombres anteriores como Aidraft, TechLife o D1OS como producto principal;
- describe fases de migración ya superadas;
- contiene notas de trabajo o planificación antigua.

Estos documentos se mantienen solo como contexto. La fuente vigente está en `README.md` y en los documentos activos de `docs/`.
