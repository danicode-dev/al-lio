# Agent Skill - D1OS V1

Use this project guide when an AI agent works on D1OS / Al-Lio.

## Role

Act as a senior full-stack engineer for a personal productivity dashboard built with Next.js App Router, Supabase, Google Calendar, local news cache, courses, hackathons, tasks, and tech opportunities.

## Operating Rules

- Read `AGENTS.md` before changing code.
- Preserve the existing product structure and visual design.
- Prefer small, verifiable changes over broad rewrites.
- Do not hardcode CSV records in frontend code.
- Do not remove existing sections unless the user explicitly asks.
- Keep generated artifacts out of the project root.

## Verification Rules

Use the cheapest check that proves the change:

- Startup readiness: `npm run verify:startup`
- TypeScript-only/refactor: `npm run typecheck`
- UI or data-loading change: `npm run verify:cheap`
- Routes, middleware, build, or startup change: `npm run verify:prod`
- Existing running server route check: `npm run smoke`

Before claiming the app is OK, run at least one relevant command and report the result.

## Startup Rules

- `npm run dev` runs startup checks automatically.
- Use `npm run dev:clean` when `.next` may be stale.
- Use `npm run restart:prod` to stop old Next processes, clean `.next`, build, smoke-test production, and start the app.
- Never assume a `.next` directory generated by `next dev` is valid for `next start`.

## Protected Fixes

Do not regress these known fixes:

- No `revalidatePath("/dashboard")` in actions.
- `StoreProvider` skips initial sync to avoid double render.
- Bloc notes keep `notesRef` and flush on unmount.
- News JSON writes catch filesystem errors for Vercel read-only runtime.
- `data/news-items.json` and `data/news-sync-status.json` are committed cache data.

## Supabase / CSV

Primary CSV source:

- `csv/oportunidades_tech_supabase_combinado.csv`

Importer:

- `npm run import:opportunities`

Remote Supabase must have `public.tech_opportunities` created from:

- `supabase/migrations/create_tech_opportunities.sql`

Courses and hackathons should show Supabase-backed data and merged tech opportunities, not hardcoded CSV rows.
